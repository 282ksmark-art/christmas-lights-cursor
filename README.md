# Christmas Lights Cursor 🎄

빨강·초록·금색·파랑 전구가 빛나는 무료 Chrome 커서 확장 프로그램입니다.

## 무료 다운로드

**[설치용 ZIP 다운로드](https://github.com/282ksmark-art/christmas-lights-cursor/raw/refs/heads/main/christmas-lights-cursor.zip)**

![크리스마스 전등 커서 디자인](cursor-preview.png)

## Chrome에 설치하기

1. 위 ZIP 파일을 다운로드하고 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭하고 `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 일반 웹페이지를 새로고침하면 커서가 적용됩니다.
6. 확장 아이콘에서 커서 사용, 전구 반짝임, 크기를 바꿀 수 있습니다.

GitHub에서 무료로 배포하는 수동 설치 방식입니다. Chrome 웹 스토어에 등록된 확장 프로그램은 아니므로 ‘Chrome에 추가’ 버튼과 스토어 자동 업데이트는 제공되지 않습니다. 관리자 정책으로 개발자 모드가 차단된 기기에서는 설치가 제한될 수 있습니다.

## 기능

- 크리스마스 전구 네 가지 색상과 은은한 반짝임
- 커서 켜기/끄기, 반짝임 켜기/끄기
- 세 가지 커서 크기: 32, 40, 48px
- 입력 영역에서는 기본 텍스트 커서 유지
- 기기의 동작 줄이기 설정 존중 및 숨겨진 탭에서 반짝임 중지

Chrome 내부 페이지, 웹 스토어, 내장 PDF 뷰어와 일부 특수 웹 요소에는 적용되지 않습니다.

## 개인정보

개인정보, 페이지 내용, 입력값, 방문 기록을 수집하거나 외부로 보내지 않습니다. 커서 설정 세 가지 값만 `chrome.storage.local`에 저장합니다. 광고, 외부 분석 도구, 원격 코드 및 네트워크 요청이 없습니다.

권한 `storage`는 설정 저장에 사용됩니다. HTTP/HTTPS 페이지에서 콘텐츠 스크립트를 실행하는 목적은 커서 스타일 적용입니다.
